CT単位講習会

行くつもりの講習会は「参加予定にする」ボタンを押すと「参加予定」タブに一覧できます。 実際に参加したら、「参加予定」タブの「参加した」ボタンを押してください。どちらもGitHubの新規Issue作成画面が 開くので、内容はそのままで投稿すると自動でこのページに反映されます(反映まで数分かかります)。 「参加した」の方は、カレンダー登録・参加履歴への記録も自動で行われます。

対象講習会リスト

条件に合致した講習会です。開催日が近い順に並んでいます。

要確認

自動判定できず、人の目でのチェックが必要な講習会です。詳細PDFを確認してください。

参加予定

「参加予定にする」を押した講習会です。実際に参加したら「参加した」ボタンを押してください (カレンダー登録・参加履歴への記録が自動で行われます)。

参加履歴

設定

値を変更して「設定変更をリクエスト」を押すとGitHubの新規Issue作成画面が開きます。そのまま投稿すると、 次回の週次リサーチから新しい条件が適用されます。
